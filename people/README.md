# Clientes reales

Un folder por persona. **No** hay un `index.html` que los liste.

Cada folder típico:

```
people/<slug>/
  index.html      ← página publicada
  styles.css
  photo.jpg
  cv.pdf
  card.pdf
  qr.png          ← QR del link público de esta página
```

Los clientes reales no se commitean (están en `.gitignore`). La plantilla vacía sí: [`_template/`](_template/).
